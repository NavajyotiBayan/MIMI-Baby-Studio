# Contributing

Thanks for your interest in MIMI Baby Studio!

## Before submitting changes

- Keep the application Windows-friendly.
- Do not commit generated PDFs, temporary media, logs, caches, or virtual environments.
- Test `start.bat` on a clean Windows installation when changing setup logic.
- Test both Video → PDF and Images → PDF after UI/backend changes.
- Keep processing local and avoid introducing unnecessary cloud dependencies.

## Pull requests

Please describe what changed, why it changed, and how you tested it.
