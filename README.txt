MIMI Baby Studio v2

A private Windows toolkit for converting videos and images into PDF files.

Run start.bat. On first run, the application is copied to:
C:\MIMI Baby Studio

The installed copy is used for normal operation and Windows background startup.

Tools:
- Video -> PDF
- Images -> PDF
- Conversion History
- Five Eye Comfort themes
- Fresh Your Mood local music player
- Server Online / Offline status and reconnect control

Useful files:
- start.bat - first-run install, dependency setup and launch
- debug_server.bat - visible troubleshooting server
- repair-dependencies.bat - repair Python/FFmpeg dependencies
- stop_server.bat - stop the local server
- uninstall-all-dependencies.bat - clean dependency/runtime reset for testing

Processing is local to this PC.
